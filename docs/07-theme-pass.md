# PROMPT 07 — The consistency pass
Do this LAST, after every screen exists. Select all screens in Stitch, then
paste this once. It replaces doing forty small corrections one at a time.

---

Apply this exact visual system to every selected screen so they look like one
product built by one team.

Colours: background #08090B on all customer kiosk screens and #FAFAF8 on all
shop-owner web screens. Card and panel surfaces #14161A on dark screens,
#FFFFFF on light screens. Borders and hairlines #23262C on dark, #E8E4DC on
light. The single accent is #C9A961 on dark screens and #A8853F on light.
Primary text #F5F3EF on dark, #1A1D22 on light. Secondary text #8A9099 on dark,
#6B7280 on light. Use the accent only for one thing per screen — never on more
than a quarter of what is visible.

Type: every heading and every large number in Playfair Display. Every label,
button, body text and caption in Manrope. Small uppercase labels get 0.26em
letter spacing and use secondary colour. Nothing smaller than 11px anywhere.

Shape: all cards and panels 20px rounded corners, all buttons full pill shape,
all image thumbnails 16px rounded corners.

Spacing: a minimum 48px margin from every screen edge, and 24px between any two
elements. If a screen feels full, remove something rather than shrinking it.

Remove from every screen if present: gradient fills on buttons, icons sitting
inside coloured circles, coloured bars or stripes along the edge of any card or
header, drop shadows on text, and any second accent colour.

Keep every screen's existing layout and content. Change only colour, type,
corner radius and spacing.
