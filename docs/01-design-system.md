# PROMPT 01 — The design system screen
Paste this first. It teaches Stitch the visual language before you ask for any
real screen, and gives you a reference sheet to point at later.

---

Create a single mobile screen, 9:16 portrait, that is a design system reference
sheet for a premium retail product called KAPADIYA & SONS.

Context: this is an AI clothing try-on mirror that stands at the entrance of a
high-end saree and lehenga showroom in Surat, India. A customer walks up, sees
herself on screen, taps a garment, and sees herself wearing it. The feeling
should be a luxury boutique changing room at night — dark, calm, expensive,
quiet. Not a tech product. Not a kiosk. A beautiful object.

Put these on the sheet, laid out generously with lots of empty space:

Colour swatches as large rounded squares with the hex code under each:
#08090B named Void, #14161A named Surface, #1E2127 named Raised,
#C9A961 named Champagne, #E8D5A8 named Champagne Light,
#F5F3EF named Bone, #8A9099 named Muted, #2C6B58 named Confirm.

A type specimen block showing Playfair Display in 64px, 40px and 28px, and
Manrope in 20px, 16px, 13px and 11px. Show the 11px sample in uppercase with
wide letter spacing, labelled "eyebrow".

A row of four button styles: a solid champagne pill button, a ghost button with
a 1px champagne outline, a plain text link in champagne, and a disabled state.

A card component: rounded 20px corners, #14161A fill, a 1px #23262C border, and
a soft shadow underneath.

A garment thumbnail component: 3:4 vertical image, 16px rounded corners, with
the garment name in 13px Manrope beneath it, and a second version showing the
selected state with a 2px champagne ring around it.

Style: background #08090B throughout. All text in #F5F3EF except labels which
are #8A9099. Generous spacing, nothing crowded, everything breathing. Thin
hairline dividers in #1E2127. No gradients, no drop shadows on text, no icons
in coloured circles.

Platform: mobile, 9:16 portrait, 1080 by 1920.
